# 使用心得

这里收录实际使用 Skill 后的观察、经验和改进方法。

新增心得时，可以阅读[写作指南](../guide/writing.md)，复制[心得记录模板](../templates/skill-note.md)，开始记录。

## 记录什么

- **具体场景**：要完成什么任务，为什么选择这个 Skill。
- **使用过程**：准备了哪些输入，如何调用，做过哪些调整。
- **实际效果**：哪些结果可以直接使用，哪些需要人工修改。
- **经验与边界**：适合什么任务，下次怎样用得更好。
