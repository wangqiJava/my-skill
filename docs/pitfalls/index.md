# 踩坑记录

记录问题发生时的上下文，以及真正验证过的解决方法。

目前还没有发布踩坑记录。新增文章时，可以按下面的顺序整理：

1. **问题现象**：预期是什么，实际发生了什么。
2. **运行环境**：相关工具版本、操作系统和前置条件。
3. **复现步骤**：最少需要哪些步骤才能再次遇到问题。
4. **排查过程**：尝试了什么，各自的结果是什么。
5. **解决方法**：最终有效的操作，以及如何验证。
6. **后续注意**：是否仍有限制，如何避免再次遇到。

## 文章目录

将文章保存到 `docs/pitfalls/`，然后在这里添加链接。具体操作见[写作指南](../guide/writing.md)。
