# Multica

`Multica` 是一个人机协作的 Agent 团队管理平台。它把人类和 AI Agent 组织成「团队」，通过任务分配、技能复用和运行时监控，让多个 Agent 协同完成复杂工作流。支持 28 种主流 AI 工具（Claude、Cursor 等），可云端使用也可本地自托管。

这篇记录根据 [Multica 官网](https://multica.ai/) 的公开信息整理。当前没有本地完整实战记录，示例用于说明工作方式，不当作已经验证过的项目结论。

## 它解决什么

当 AI Agent 从「单兵作战」走向「团队协作」时，需要解决的问题不再是单个提示词的质量，而是：

- **任务分配**：谁做什么？人类和 Agent 的边界在哪里？
- **自主执行**：Agent 能否独立完成任务，而不是每步都等人类确认？
- **技能复用**：一个 Agent 学会的能力，能否被其他 Agent 复用？
- **运行时监控**：如何观察 Agent 的执行状态，必要时介入？

`Multica` 把这些能力产品化，让团队可以像管理人类员工一样管理 Agent 团队。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 任务分配 | 将复杂任务拆解并分配给不同 Agent 或人类 |
| 自主执行 | Agent 可独立完成任务，减少人工干预 |
| 技能系统 | 可复用的 Skill，跨 Agent 共享能力 |
| 运行时监控 | 实时观察 Agent 执行状态，支持中途介入 |
| 多工具集成 | 支持 28 种主流 AI 工具，不绑定单一平台 |
| 自托管 | 源代码可用，可部署到自有服务器 |

## 适用场景

- **复杂工作流**：需要多个 Agent 协同完成的任务（如软件开发、内容生产）
- **人机协作**：人类负责决策和审核，Agent 负责执行和生成
- **技能沉淀**：将团队的最佳实践封装为可复用的 Skill
- **成本优化**：根据任务复杂度选择不同成本的 Agent
- **合规需求**：需要数据本地化或私有化部署的场景

不适合：简单的单轮对话、一次性查询、或只需要单个 Agent 的场景。

## 安装与准备

### 云端使用

直接访问 [multica.ai](https://multica.ai/) 注册账号即可使用。

### 本地自托管

```bash
# 克隆仓库
git clone https://github.com/multica-ai/multica.git
cd multica

# 安装依赖（具体命令以上游文档为准）
npm install

# 启动服务
npm run dev
```

### 配置 AI 工具

在设置中添加需要使用的 AI 工具（如 Claude、Cursor 等），配置对应的 API Key。

## 实际用法

### 创建 Agent 团队

1. 定义团队角色（如「前端开发」「后端开发」「测试」）
2. 为每个角色分配对应的 AI 工具
3. 配置可复用的 Skill

### 分配任务

```text
任务：实现用户登录功能

分配：
- 前端 Agent：实现登录表单和状态管理
- 后端 Agent：实现认证 API 和数据库查询
- 测试 Agent：编写单元测试和集成测试
```

### 监控执行

在运行时仪表盘中观察各 Agent 的执行进度，必要时介入调整。

### 输出与效果

一次完整的团队协作应留下：

1. 任务分解记录
2. 各 Agent 的执行日志
3. 最终交付物（代码、文档等）
4. 可复用的 Skill（如有）

## 踩坑与解决

- **任务边界不清**。Agent 之间职责重叠会导致重复工作或冲突。建议在分配时明确输入输出和接口约定。
- **技能复用陷阱**。不是所有 Skill 都适合跨场景复用，环境依赖和上下文假设可能导致失败。
- **监控过度**。频繁介入会打断 Agent 的自主执行，降低效率。建议只在关键节点检查。
- **工具绑定**。虽然支持 28 种工具，但不同工具的能力差异可能导致 Skill 不兼容。
- **把示例当成实战结论**。本页目前是基于上游公开文档的整理，尚未记录本地完整安装、配置和验证结果。

## 使用心得

从上游文档看，这个产品最有价值的两点：一是「团队视角」——不再把 Agent 当作独立工具，而是组织成协作团队；二是「技能复用」——将最佳实践沉淀为可跨 Agent 共享的 Skill。

代价是学习曲线比单工具使用要陡，需要理解任务分解、角色定义和监控机制。实际体验如何——任务分配是否顺手、Skill 复用是否稳定、多 Agent 协同是否高效——等本地跑过真实案例再补。

## 与同类产品的区别

| 特性 | Multica | 单 Agent 工具 |

| 技能复用 | 跨 Agent 共享 | 仅限当前会话 |
| 部署方式 | 云端或自托管 | 通常仅云端 |
